Final observed state: all four isolated release services are stopped, all release volumes and the new portfolio database are retained, and the original PostgreSQL service is running healthy. Unrelated containers were not changed.

Preparation-only tooling installed: detect-secrets 1.5.0 (seven Python tool packages) and Mermaid 12.2.0 (117 npm tool packages), inside ignored repository-local caches/directories. Application dependency locks were unchanged. Existing Playwright/Chromium and the Next Sharp dependency were reused.

The actual detector is detect-secrets with all default plugins, explicit tracked/untracked candidate paths and `--no-verify` (no external credential validation). Tool installation/cache is repository-local and ignored. Network metadata refresh failed during one final retry; the completed scan used the already installed tool in offline mode. No scanner findings were suppressed, and raw hashed detector output stays private. [Reviewed non-secret findings](evidence/phase13a-secret-review.json) and [documentation checks](evidence/phase13a-doc-checks.json) describe their practical limits. No claim of an exhaustive secrecy or security certification is made.
